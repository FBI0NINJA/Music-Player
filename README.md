# 🎧 Music Player Pro

A modern desktop music player built with Python that allows users to search, stream, and download songs directly from YouTube.

---

## 🚀 Features

- 🔍 Search for any song بسهولة
- ▶️ Instant playback with no lag
- ⏭️ Auto-play next track
- 📃 Playlist sidebar
- 🖼️ Song thumbnail preview
- 🔊 Volume control
- ⬇️ Download songs as MP3
- 🎨 Clean and modern UI

## 🛠️ Technologies Used

- Python
- Tkinter (GUI)
- yt-dlp (YouTube extraction)
- VLC (Audio playback)
- FFmpeg (Audio conversion)
- Pillow (Image processing)
- Requests (HTTP requests)
